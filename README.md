## Project Overview

This project is an interactive dashboard that visualizes data from the Belly Button Biodiversity study. It allows users to select an individual and view the top 10 microbial species (OTUs) found in their sample, along with their demographic information. The dashboard includes a bar chart for the top 10 OTUs and a bubble chart showing all microbial species, with markers sized by sample values and colored by OTU IDs. The charts and metadata update dynamically based on user selection. The app was deployed using GitHub Pages for easy access.
